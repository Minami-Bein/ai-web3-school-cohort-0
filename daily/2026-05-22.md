## 📚 学习内容

### 智能合约基础（Smart Contract）

**核心概念：**

**状态（state）：**
合约在链上存储的数据。例如：一个代币合约的 state 包括每个人的余额（mapping）。state 只能通过交易改变。

**函数（function）：**
合约暴露的可执行逻辑。调用函数 = 发起一笔交易，消耗 gas。函数可以是：
- read（view/pure）：不修改状态，不需要签名，免费
- write：修改状态，需要签名，消耗 gas

**事件（event）：**
链上发生的重要动作记录。用于通知链下应用（"听到了吗？链上发生了一件事"）。Event 不存储在状态里，但可以用于构建索引和触发逻辑。

**gas：**
执行合约操作的"燃料"。每一笔交易都需要 gas，gas 费用 = gas price × gas used。设计合约时要考虑 gas 优化（不要在链上存不必要的数据）。

### Dev Stack（开发栈）

常用工具：
- **Solidity**：智能合约编程语言（类 JS 语法）
- **Foundry / Hardhat**：合约开发、测试、部署框架
- **ethers.js / viem**：链上交互的 JavaScript 库
- **Alchemy / Infura**：RPC 节点服务（不用自己跑全节点）
- **OpenZeppelin**：安全、可复用的合约库（ERC20、ERC721、AccessControl）

**一个简单合约的结构：**
```
contract Counter {
    uint256 public count;  // state variable
    
    function increment() public {  // function
        count += 1;  // 修改 state
    }
    
    event CountIncremented(uint256 newCount);  // event
}
```
