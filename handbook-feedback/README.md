# Handbook Feedback

学习过程中发现的问题、卡点、错别字、概念不清或建议，整理在这里。

每条 feedback 包含：
- **Handbook 页面链接**
- **问题描述**
- **建议改法**
- **来源**（个人学习心得）

## 提交方式

在 `handbook-feedback/` 目录下创建以日期命名的 Markdown 文件，例如：

```
handbook-feedback/YYYY-MM-DD-issue-title.md
```

## 文件命名规范

`日期-问题简述.md`

例如：`2026-05-23-密码学章节措辞不清.md`

## Feedback 模板

见 `feedback-template.md`
