# Proposal Memo

## 项目概述

Cat-Agent 是一个让宠物拥有自主消费权的 AI Agent 系统。宠物通过多模态 IoT 设备（摄像头+麦克风）表达需求，AI 分析并确认意图后，通过 Web3 智能合约钱包在预设预算内完成支付。

## 解决的问题

**宠物需求被动等待：** 现有智能喂食器只能"定时定量"，无法感知宠物的真实情绪和即时需求。

**宠物消费缺乏边界：** 没有机制限制宠物（或熊孩子）乱买的上限。

**宠物数字身份缺失：** 宠物在数字世界中没有独立的经济账户和身份。

## 解决方案

**感知层：** 多模态 AI（音频频率分析 + 视觉姿态识别）实时理解宠物意图。

**确认层：** AI 主动发起物理反馈（激光笔指向商品+扬声器发出询问音），宠物正向响应（高频叫声/慢眨眼）才确认购买，置信度必须 >90%。

**支付层：** CAW Warrant（链上授权）+ Safe{Wallet}（每日预算限制）+ x402（机器微支付）三位一体，确保宠物不能超支。

**反馈层：** RLPF（宠物反馈强化学习），根据宠物实际进食/玩耍行为调整下次推荐权重。

## 技术架构

```
[IoT 摄像头/麦克风]
        │
        ▼
[多模态 AI 推理]  ← Z.AI 推理平台
        │
        ▼
[意图置信度引擎]  ← 连续两轮交互，置信度 >90% 才触发购买
        │
        ▼
[CAW Warrant 检查]  ← Budget / Scope / Time Window 三重校验
        │
        ▼
[Safe{Wallet} 执行支付]  ← Session Key 签名，链上记录每笔交易
        │
        ▼
[x402 受保护 API]  ← 自动完成 USDC 支付，获取商品/服务
```
