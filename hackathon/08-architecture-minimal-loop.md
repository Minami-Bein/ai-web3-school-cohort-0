## 二、最小闭环核心路径（精简版）

```
猫咪行为输入
     │
     ▼
┌─────────────────────────┐
│   Z.AI 多模态推理        │   ← SDK 调用
│  音频 + 视觉 → 意图置信度 │
└────────────┬────────────┘
             │ confidence_score
             ▼
┌─────────────────────────┐
│  置信度引擎              │   ← 阈值判定
│  ≥90% → CONFIRMED       │
│  <90% → DECLINED        │
└────────────┬────────────┘
             │ CONFIRMED
             ▼
┌─────────────────────────┐
│  CAW Policy Engine      │   ← 权限校验
│  Budget + Scope + Time  │
│  PASS → / FAIL → 拒绝   │
└────────────┬────────────┘
             │ PASS
             ▼
┌─────────────────────────┐
│  Safe{Wallet}           │   ← 链上执行
│  Session Key 签名        │
│  USDC Transfer          │
└────────────┬────────────┘
             │ tx_hash
             ▼
        交易完成
        收据存档
        RLPF 反馈
```

## 三、关键模块数据流

```
输入数据
├── audio_raw        原始音频（WAV/PCM）
├── video_frame      摄像头截图（JPEG）
├── cat_id           宠物身份（ERC-8004 NFT tokenId）
└── owner_wallet     主人钱包地址（EOA 或 Safe）

意图分析（Z.AI）
├── audio_features   { frequency, duration, pitch }
├── visual_features  { pose, eye_contact, tail_position }
├── intent           { category, confidence_score }
└── decision         { action: "buy" | "decline", reason }

CAW Warrant 检查
├── budget_check     { daily_limit, per_tx_limit, daily_spent }
├── scope_check      { endpoint_whitelist, contract_whitelist }
├── time_check       { valid_from, valid_until, is_expired }
└── result           { approved: bool, rejection_reason?: string }

链上交易
├── tx_hash          Ethereum transaction hash
├── block_number     Sepolia block height
├── from_address     Safe{Wallet} address
├── to_address       商户/外卖合约地址
├── amount           USDC amount in smallest unit
├── gas_used         Gas consumed
└── status           "confirmed" | "failed"

审计日志
├── intent_log       IPFS CID → 意图分析原始记录
├── payment_log      IPFS CID → 支付交易记录
├── event_hash       链上 Event 哈希锚定
└── rlpf_weights     偏好权重更新记录
```

## 四、失败路径（同样需要完整记录）

```
任何节点 FAIL ──▶ 拒绝交易 ──▶ 记录拒绝原因 ──▶ 通知主人（Telegram）

失败类型
├── audio_failed     音频采集失败 → 跳过音频维度，仅视觉判断
├── zai_timeout      Z.AI API 超时 → 使用缓存结果或降级拒绝
├── confidence_low    置信度 <90% → action=decline，不触发支付
├── budget_exceeded   日预算耗尽 → policy_reject，告知主人
├── scope_violation  调用非白名单 → scope_reject，AllowlistGuard 拦截
├── warrant_expired  Warrant 过期 → warrant_reject，重新授权
├── safe_revert      链上交易回退 → tx_failed，记录 revert reason
└── payment_timeout  x402 支付超时 → 降级重试或拒绝
```
