# Sponsor / Mentor 问题清单

## 给 Cobo 的问题

### 技术集成类
1. CAW Warrant 在测试网（如 Sepolia）的注册流程是什么？有没有 Step-by-Step 文档或参考代码？
2. Safe{Wallet} 的 Session Key 生成和部署，有没有面向开发者的 SDK 或 CLI 工具？支持哪些网络？
3. SpendingLimitModule 和 AllowlistGuard 在部署时有没有现成的 Template？如何在测试网验证其功能？
4. CAW Warrant 的 Budget / Scope / Time Window 参数，谁来支付 Gas 费用？是 Agent 钱包还是主人钱包？
5. Session Key 的权限撤销机制是什么？主人可以随时撤销吗？撤销后链上确认延迟多久？

### 产品设计类
6. Cobo 是否有面向宠物/IoT 场景的钱包解决方案参考案例？类似 Cat-Agent 这种"宠物自主消费"场景有没有先例？
7. CAW Warrant 支不支持"条件触发"类型的授权？比如"只有当 AI 置信度 >90% 时才授权支付"？
8. 在 Cobo 的规划中，Agent 钱包和人类钱包的安全性标准是否一致？还是 Agent 有额外的安全要求？

### 商务合作类
9. 如果 Cat-Agent 项目在黑客松获奖，Cobo 是否愿意提供额外的技术支持和云资源？
10. Cobo 是否有宠物经济的生态合作资源？比如宠物食品供应商、宠物智能硬件厂商等？
