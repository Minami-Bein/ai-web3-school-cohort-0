### 安全风险

| 风险 | 概率 | 影响 | 缓解措施 | 残余风险 |
|------|------|------|---------|---------|
| Session Key 被恶意软件窃取 | 低 | 高 | Session Key 加密存储，每日重置，使用后即销毁 | 低 |
| CAW Warrant 被恶意修改 | 低 | 高 | Warrant 由主人主私钥签名，Agent 只有执行权 | 极低 |
| 猫咪连续触发购买（日累计超过预算）| 低 | 低 | Safe SpendingLimitModule 链上硬限制 | 极低 |
| Prompt Injection（恶意指令注入）| 低 | 中 | 外部输入（猫咪行为）不解析为命令 | 极低 |
| IPFS 存储隐私（宠物行为数据泄露）| 中 | 中 | 仅链上存储交易哈希，原始数据加密存储 | 低 |

---

## 红线（永不跨越）

1. Agent 永远不能独立完成 approve / permit / transferFrom 操作
2. 任何链上操作必须有主人主私钥授权的 Session Key 作为最终签名
3. 日累计消费不超过 CAW Warrant 设定的硬上限
4. 不存储任何主人的助记词或主私钥
